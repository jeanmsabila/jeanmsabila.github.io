# Jean Abel Msabila — academic website

## Publish on GitHub Pages (no coding or installation required)
1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. Sign in to GitHub. Create a PUBLIC repository named YOURUSERNAME.github.io, replacing YOURUSERNAME with your actual GitHub username. If that repository already exists, use it and retain a backup before replacing existing files.
3. In the repository, select Add file → Upload files. Drag the CONTENTS of the extracted folder into the upload area: index.html, styles.css, assets, and README.md. Upload the assets folder itself so the photo and CV stay inside it. index.html must be at the repository root, not inside another website folder.
4. Click Commit changes. Use the main branch.
5. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch. Select main and / (root), then Save.
6. Open https://YOURUSERNAME.github.io/. Initial publishing can take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/quickstart

## Preview before publishing
Open index.html in a browser. All layout files, the portrait, and the downloadable CV are included. Internet is needed only for the external professional links and email service. No build step, dependencies, accounts, analytics, or third-party fonts are required.

## Update later
Edit index.html to change text and paper listings. Edit styles.css to change colours or layout. Replace assets/Jean_Msabila_CV.pdf to update the CV, keeping the filename unchanged. Commit updates to main to republish.
